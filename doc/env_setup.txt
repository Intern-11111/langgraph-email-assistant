<-------------------------Environment Setup Documentation------------------------------>


 ---------------1. Create a Virtual Environment 
Creating a virtual environment keeps dependencies isolated.

On Windows:
```bash 
python -m venv venv
venv\Scripts\activate
```
Once activated, all packages will install inside this environment.

---------- 2. Install Required Dependencies

Create a `requirements.txt` file with the following content:
```text
langgraph
langchain
langchain-openai
python-dotenv
openai
```

Install dependencies using:

```bash
pip install -r requirements.txt
```

-------------- 3. Environment Variables Setup (.env File)

Create a `.env` file in the project root directory.

Example `.env` file:

```text
OPENAI_API_KEY=your_api_key_here
```

The project uses `python-dotenv` to securely load this key.

--------5. Verify Environment Setup

To confirm everything is working:
1. Activate the virtual environment
2. Run any Python file, for example:

```bash
python src/triage/triage_node.py
```
