<---------------ReAct-Loop--------------------->

Once Triage  classifies an email as respond / act , the agent enters the ReAct loop . 
The loop is intentionally split into two clear phases:

1.  Reason  – decide what to do next
2.  Act (Tool)  – execute the chosen action using a tool


-----------Step 1: Reason (Decision-Making)

Purpose:  Understand the email and decide the next action.
What happens:        
     The agent reads the email subject and body.
     It interprets the user’s intent (e.g., scheduling, asking for contact info, requesting a reply).
     It decides one next action only.

Possible actions:        
     `read_calendar`
     `lookup_contact`
     `reply`

Output:        
```json
{
  "thought": "Why this action is needed",
  "action": "read_calendar | lookup_contact | reply",
  "action_input": {}
}
```
------------------Step 2: Act via Tool (Execution)

Purpose:  Perform the action chosen during reasoning.
What happens:        
         The agent does not think again .
         It simply executes the selected action using the corresponding tool.

Action → Tool Mapping:        
      `read_calendar` → Calendar tool is called
      `lookup_contact` → Contact lookup tool is called
      `reply` → Reply content is prepared (no external tool)

Output :        

```json
{
  "tool_result": { ... }
}
```
 If triage result is ignore  or  notify_human,the ReAct loop is skipped.
 Only pre-approved (safe) tools run automatically.
 This process supports later integration of  Human‑in‑the‑Loop (HITL)  checkpoints for risky actions.
